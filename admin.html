API Integration Information

This admin panel demonstrates how user management would work with KeyAuth in a production environment.

In a real implementation, you would need a backend API that connects to KeyAuth's admin endpoints:

POST /api/users/list - Fetch all users

POST /api/users/activate - Activate a user

POST /api/users/deactivate - Deactivate a user

POST /api/users/delete - Delete a user

POST /api/users/reset-hwid - Reset user's HWID
